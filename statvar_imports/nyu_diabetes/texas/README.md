## NYU_Texas_Diabetes Import

This import utilizes official diabetes mortality data from CDC WONDER, detailing county-level death statistics.
-----

### ⚙️ Workflow

The workflow for this data import involves two main steps: downloading the necessary files and then processing them.

#### Step 1: Download the Source Data

To acquire the necessary data files, execute the download script `download.py`:

```bash
python3 download.py
```

The script connects to the CDC WONDER saved query (`https://wonder.cdc.gov/controller/saved/D158/D516F171`), automates the session agreement, and downloads the county-level diabetes mortality dataset to `input_files/Death_Data_Cross_Tabulation_data.csv`.

### Autorefresh type

This import uses a fully automated refresh process.

-----

#### Step 2: Process the Files

After successfully downloading the files, run the processing script to generate the final output artifacts.

#### **Execution Commands**

The final output is generated by processing the downloaded data using the `stat_var_processor.py` script located in the `data/tools/statvar_importer/` directory:

```bash
python3 ../../../tools/statvar_importer/stat_var_processor.py \
  --input_data=input_files/*.csv \
  --pv_map=Death_Data_Cross_Tabulation_pvmap.csv \
  --config_file=Death_Data_Cross_Tabulation_metadata.csv \
  --existing_statvar_mcf=gs://unresolved_mcf/scripts/statvar/stat_vars.mcf \
  --output_path=output_files/Texas_Diabetes \
  --output_counters=counters/Texas_Diabetes_counters.csv
```
