# US_UrbanSchool_Enrollment Import

This import focuses on urban school enrollment data across the United States. It includes data for student enrollment counts, broken down by gender, race, Limited English Proficiency, and disability status (Section 504 and Individualized Education Program).

-----

## 📊 Dataset Coverage

- **Source**: U.S. Department of Education, Civil Rights Data Collection (CRDC)
- **Provenance URL**: [https://civilrightsdata.ed.gov/data](https://civilrightsdata.ed.gov/data)
- **Geographic Entities**: Public schools across the United States identified by NCES School IDs (`nces/...`).
- **Temporal Scope**: Biennial data covering school years 2009-10 (2010), 2011-12 (2012), 2013-14 (2014), 2015-16 (2016), 2017-18 (2018), 2020-21 (2021), 2021-22 (2022), and 2023-24 (2024). Future releases are automatically supported.
- **Statistical Variables**: Student enrollment headcounts broken down by race, gender, Limited English Proficiency (LEP/EL), disability status (IDEA and Section 504), and Juvenile Justice facility status.

-----

## 📋 Prerequisites

1. **Python Dependencies**: Ensure required Python packages are installed:
   ```bash
   pip install -r ../../../requirements_all.txt
   ```
2. **Schema Access**: Access to Data Commons schema MCF (`gs://unresolved_mcf/scripts/statvar/stat_vars.mcf`) for reusing existing StatisticalVariables.
3. **Working Directory**: All commands below assume your current working directory is:
   ```bash
   cd statvar_imports/us_urban_school/enrollment
   ```

## ⚙️ Workflow

The workflow for this data import involves two main steps: downloading the necessary files and then processing them.

### Step 1: Download the Source Data

To acquire the necessary data files, execute the download script `../download.py` from the `enrollment/` directory:

```bash
python3 ../download.py --data_type=enrollment
```

All downloaded files will be stored in `input_files/`.

-----

### Step 2: Process the Files

After successfully downloading the files, run the processing script to generate the final output artifacts. A data quality filter is applied from the `pv_map` (`#Filter,Allow=int(value) >= 0`) which ensures only non-negative counts are included in the final output. There are two ways to do this:

**Option A: Use the `run.sh` script (Recommended)**

The `run.sh` script automates the processing of all the downloaded files and emits counter metrics:

```bash
bash run.sh
```

**Option B: Manually Execute the Processing Script**

#### **Execution Commands**

The final output is generated by processing the downloaded data using the `stat_var_processor.py` script located in `tools/statvar_importer/` (run from `statvar_imports/us_urban_school/enrollment/`):

##### --- 1. Process 2010, 2012, and 2014 Files (Older XLSX format) ---

# Race and Sex (2010-2014)
```bash
python3 ../../../tools/statvar_importer/stat_var_processor.py \
  --input_data="input_files/2010_Enrollment.xlsx,input_files/2012_Enrollment.xlsx,input_files/2014_Enrollment.xlsx" \
  --pv_map=race_and_sex_pvmap.csv \
  --config_file=metadata.csv \
  --existing_statvar_mcf=gs://unresolved_mcf/scripts/statvar/stat_vars.mcf \
  --output_path=output_files/enrollment_by_race_and_sex_2010_2014_output \
  --output_counters=counters/enrollment_by_race_and_sex_2010_2014_counters.csv \
  --recon_property=variableMeasured \
  --log_level=-2 \
  --log_every_n=1000
```
