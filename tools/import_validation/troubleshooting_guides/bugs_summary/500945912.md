# Bug 500945912 Summary

## Problem Description
A failure was reported in the download script for an import. Additionally, there were unexpected deletions of data series for certain Statistical Variables. It was identified that these deletions occurred because a specific StatVar wasn't properly recognized or was missing from the internal schema, leading the system to treat existing data as obsolete.

## Resolution
The issue was resolved by adding the `-existing_statvar_mcf` parameter to the `manifest.json` file. This ensures that the system correctly identifies and preserves the existing Statistical Variables during the import process. The fix was verified as successful in subsequent runs.
